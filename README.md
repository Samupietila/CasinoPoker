## Introduction
CasinoPoker is a browser-based poker game that showcases the developer's skills in using modern web technologies. This project offers a realistic and entertaining poker experience directly in the browser without the need to download any additional software.

## Features
- Interactive gaming platform with dynamic and engaging animations and graphical elements.
- Simple and intuitive user interface suitable for both beginners and experienced players.
- Fast and smooth performance with optimized code for an uninterrupted gaming experience.

## Technologies Used
- JavaScript
- CSS
- HTML

## Installation
To run this project locally, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/Samupietila/CasinoPoker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CasinoPoker
   ```
3. Open `index.html` in your preferred web browser.
